# Fitness Tracker App 💪

Nowoczesna aplikacja do śledzenia postępów fitness z interfejsem glass morphism.

## Funkcjonalności

- 📊 **Panel główny** - Przegląd dziennych postępów
- ⚖️ **Kalkulator BMI** - Obliczanie i śledzenie BMI
- 🔥 **Tracker Kalorii** - Rejestrowanie spożytych kalorii
- 👟 **Licznik Kroków** - Śledzenie dziennej aktywności
- 🍽️ **Plan Posiłków** - Spersonalizowany plan żywienia
- 📈 **Statystyki** - Szczegółowa analiza postępów

## Technologia

- **React 18** - UI Framework
- **Vite** - Build tool
- **Tailwind CSS** - Styling
- **Local Storage** - Data persistence

## Instalacja

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
